# UI Showcase

一场景预览全部风格 UI（顶栏切换，不必每个面板单独场景）。

## 打开

`Assets/Scenes/UIShowcase/UIShowcase.unity` → Play

## 顶栏

| 按钮 | 内容 |
|------|------|
| 主菜单 / 战役 / 配置 / 商店 / 设置 | `MainMenu.uxml` 子面板 |
| 老虎机 | `BuffSelection` 老虎机 |
| 结算 | Cyberpunk Neon 结算页（假数据） |
| 暂停 | Pause 菜单 |

主菜单「无尽 / 战役」启动进关在本场景已禁用（`previewOnly`）。
