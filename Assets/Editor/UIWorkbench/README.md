# UI 调整工具

入口：Rebound Protocol → UI Workbench，或 Project 中右键 UXML / USS → UI 调整工具。

默认画布为 1080 × 1920，自动缩放以完整显示竖屏。可调整画布尺寸，或关闭自动适应后手动缩放。

选择 UXML 后会加载关联 USS。在画布中直接点击 UI 元素，蓝框表示当前选中项。被遮挡或隐藏的元素可以从画布下方的列表选择。右侧参数面板会带出当前值，按尺寸、布局、位置、外间距、内间距、文字和外观分组。尺寸用数值框和 px / % / 自动单位，排列和对齐用中文下拉框，颜色用拾色器，不透明度用滑杆。改动立即预览，停顿后通过 Unity 重新导入草稿确认。

数字控件旁的 ↶ 移除该项覆盖；Ctrl+Z 撤销编辑。没有 USS 时可以创建并关联一个。具有唯一 name 的文字元素支持修改显示文字。仅具有 class 的元素会提示共享样式，修改作用于同类元素。复杂源码编辑收在左侧高级选项。

修改先保留为草稿。点击保存才写入源文件；关闭时可以保存或放弃。源文件每 0.5 秒检查：无草稿时同步最新内容，有草稿时阻止覆盖冲突。保存前备份位于 Library/UIWorkbench/Backups，长期备份请另存或提交版本控制。

预览不执行游戏脚本，动态生成的内容和动画需在 Game 视图确认。Package 内文件应先复制到 Assets。Jobs 菜单已隐藏，保留依赖的 Burst 功能。


画布操作：滚轮以鼠标位置为中心缩放（5%–400%），右键按住拖动画布。放开右键或窗口失去焦点会结束拖动。“适应并居中”恢复完整竖屏预览。缩放和平移不会改动 UI 参数或源文件。

点选按元素边界判断，可选择 picking-mode=Ignore 的装饰元素；优先选择可见内容，再选择小控件。重叠处再次左键点击可循环选择。元素列表保留同类元素各自的条目，并显示层级位置；复杂遮挡仍可从列表选择。
