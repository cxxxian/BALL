# 背景预留区域

依据 SampleScene.unity、FlipperController.cs、DefaultGameConfig.asset 和 ActionHudLayout.cs 的现有布局制作。坐标以图片左上角为原点，百分比以图片宽高计算。

- 挡板场景铰点：X=±2.2，Y=-6.9000006。运行时 HudClearanceY=0.55，上移至 Y≈-6.35。
- 台面：10.83×19.25，中心 Y=-0.375。挡板铰点对应图片 X≈29.69% / 70.31%，Y≈81.04%。
- 挡板长度配置：1.9，左挡板角度 -30° 至 +15°，右侧镜像。背景在 X=17%～83%、Y=75%～91% 保留连续暗色空间，不绘制内收框、底部楔形或亮线。
- Action HUD 参考画布为 720×1280。底栏高 96，离底至少 8，并跟随 Screen.safeArea。技能热区 118×88，横向中心 12% / 88%；武器条位于 30%～70%。
- 图片最底部 9% 全宽保持暗色留白，不烘焙按钮、技能槽或武器条。
- 灯带主要位于外侧和上部。侧框在底部向外退，不向中间收拢，不封闭落球口。

这是背景素材的预留方案，并非已在运行中的 Unity 画面完成叠加验证。全面屏安全区由现有 HUD 代码继续处理。
